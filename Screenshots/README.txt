
# Hospital Billing and Patient Classification

## Description
This project calculates hospital bills and classifies patient payment status based on billing and payment details.

## Features
- Accepts patient details.
- Calculates hospital bills.
- Applies applicable concessions.
- Checks payment details.
- Displays payment status.

## Concepts Used
Variables, data types, operators, conditional statements, loops, and lists.

## Language
Python 3

## How to Run
python hospital_billing.py
